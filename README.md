# UV-Vis Spectroscopy Data Analysis

## Objective
To analyse UV-Vis spectroscopy data using Python and identify the wavelength corresponding to maximum absorbance.

## Tools
- Python
- pandas
- Matplotlib

## Method
1. Load wavelength and absorbance data from a CSV file.
2. Identify the maximum absorbance value.
3. Determine the corresponding wavelength.
4. Plot and save the absorption spectrum.

## Dataset
This project uses simulated data for learning and demonstration. It does not represent experimental measurements.

## Results
The simulated dataset has a maximum absorbance of approximately 0.8634 a.u. at 485 nm.

## Limitations
The wavelength of maximum absorbance is calculated from the supplied dataset. It is not, by itself, sufficient to identify a material or establish its optical band gap.

## Future Improvements
